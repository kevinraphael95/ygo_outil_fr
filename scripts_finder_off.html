Scripts Finder Officiels

Pour chaque carte custom non taguées (identique à l'officielle) : trouve la carte officielle du même nom dans les CDB officiels, prend son script en remplaçant l'ID par l'ID custom.

Configuration

Plusieurs tags possibles, séparés par « ; ». Cherchés dans la description EN et FR, insensible à la casse. Vide = aucune carte exclue.
Un script d'un sous-dossier « official » est prioritaire sur les variantes (goat, rush…).
Utilisé seulement avec « Ignorer les cartes qui ont déjà un script ».
