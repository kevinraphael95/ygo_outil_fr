Réparer un CDB

Corrige la race et l'attribut manquants (« ??? » dans EDOPro) d'un CDB déjà créé, sans le recréer. Les IDs, les noms, les effets et tout le reste ne sont pas touchés.

Configuration

Un nouveau fichier « nom_repare.cdb » est téléchargé pour chacun. Ton CDB d'origine n'est pas modifié.
Les JSON dont viennent les cartes. Utiles pour les cartes custom. Les cartes sont retrouvées par leur nom, avec ou sans « (Buff) », puis départagées par ATK/DEF/niveau.
Vide = tous les CDB de data/cdb/en du dépôt GitHub ygo_outil_fr. Servent aux cartes officielles et à celles que le JSON ne couvre pas.
Séparés par « ; ».
