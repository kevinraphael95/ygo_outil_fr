      ⚜️ À propos

      Cet outil permet de rechercher des cartes Yu-Gi-Oh! par leur nom dans plusieurs langues, de générer un JSON compatible avec l'éditeur ygopro.org, de télécharger les illustrations officielles, de traduire des decklists entières, et de traduire des fichiers .cdb EDOPro/YGO Pro.

      💾 Base de cartes locale

      Pour des recherches instantanées et zéro requête API, l'app peut télécharger toute la base de cartes (~30 Mo) dans le navigateur (IndexedDB). Une seule fois. Ensuite, tout fonctionne hors-ligne.

      Utilise le bouton 🔄 du header pour synchroniser si une nouvelle version est disponible.

      📦 Traduction .cdb

      Dépose un fichier .cdb (base SQLite EDOPro/YGO Pro) dans l'onglet dédié. L'outil remplace les noms et effets des cartes par leur version française quand elle existe, puis te redonne un _fr.cdb prêt à utiliser.

      Mode VAACT : pour les cartes dont l'effet a été modifié par le projet VAACT, conserve l'effet original (anglais) et ajoute la traduction officielle française en dessous.

      🌐 Langues supportées

      La recherche accepte les noms de cartes dans toutes les langues gérées par l'API YGOPRODeck :

      🇫🇷 Français
      🇬🇧 Anglais
      🇯🇵 日本語
      🇩🇪 Deutsch
      🇮🇹 Italiano
      🇵🇹 Português

      En mode Auto, la recherche essaie d'abord en français, puis bascule automatiquement en anglais si aucune carte n'est trouvée.

      📄 Format JSON généré

      Le JSON suit le schéma compatible-card du card maker ygopro.org : version, name, level, type, icon, effect, atk, def, serial, copyright, attribute, id, rarity, pendulum, variant, link, layout, boxSize.

      ⚠️ Limitations

      • Toutes les cartes n'ont pas de traduction française officielle ; dans ce cas, le nom anglais est conservé.
      • Le champ serial (numéro de set) n'est pas fourni par l'API — laisse vide ou clique RANDOMIZE dans l'éditeur.
      • Les images ne sont pas stockées localement — elles sont chargées depuis images.ygoprodeck.com (mise en cache navigateur).

      ⚖️ Mentions

      Données fournies par l'API YGOPRODeck. Yu-Gi-Oh! est une marque de Konami. Cet outil est non officiel et à usage personnel.
