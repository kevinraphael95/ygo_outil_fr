      Détail de la carte

      ⚜️ À propos

      Cet outil permet de rechercher des cartes Yu-Gi-Oh! par leur nom dans plusieurs langues, de générer un JSON compatible avec l'éditeur ygopro.org, de télécharger les illustrations officielles, de traduire des decklists entières, de générer des fichiers .ydk pour EDOPro/YGOPro, et de convertir des fichiers .cdb EDOPro/YGO Pro en JSON ou en .cdb traduit.

      💾 Base de cartes locale

      L'app charge automatiquement 2 fichiers JSON locaux :

      • data/cards-db.json — toute la base YGOPRODeck (EN + FR, ~14 500 cartes)
      • data/yugipedia-db.json — base Yugipedia (anime, manga)

      Aucune requête API au démarrage, tout est instantané et fonctionne hors-ligne.

      📋 Decklist — 3 actions possibles

      • Transformer en JSON — un JSON par carte (ZIP) + CSV Manager.
      • Traduire la decklist — traduit chaque nom (ex: EN → FR) et donne la decklist traduite.
      • Générer un fichier .ydk — format texte prêt pour EDOPro, YGOPro, YGO Omega. Les sections Main, Extra et Side sont automatiquement détectées. Les cartes anime sont résolues via le dictionnaire CUSTOM_IDS dans script.js.

      📦 Traitement .cdb

      Dépose un fichier .cdb (base SQLite EDOPro/YGO Pro) dans l'onglet dédié. Tu peux ensuite :

      • Le traduire — les noms et effets passent en français. Sortie : _fr.cdb.
      • Le convertir en JSON — un JSON par carte (ZIP) + CSV Manager, prêt pour l'éditeur ygopro.org.

      Préserver les effets modifiés : pour les cartes dont l'effet a été modifié par un mod custom (VAACT, Project Ignis, fan-made…), conserve l'effet original du .cdb tel quel.

      🟣 Fallback Yugipedia (cache local)

      Pour les cartes absentes de la base YGOPRODeck (cartes récentes, anime, manga…), l'app utilise le fichier data/yugipedia-db.json chargé localement.

      Aucune requête réseau n'est effectuée : tout est instantané.

      🌐 Langues supportées

      📄 Format JSON généré

      Le JSON suit le schéma compatible-card du card maker ygopro.org : version, name, level, type, icon, effect, atk, def, serial, copyright, attribute, id, rarity, pendulum, variant, link, layout, boxSize.

      📦 Format .ydk généré

      Le fichier .ydk suit le format standard utilisé par EDOPro, YGOPro et YGO Omega :

      • #main — cartes du Main Deck
      • #extra — cartes de l'Extra Deck
      • !side — cartes du Side Deck

      Chaque carte est identifiée par son passcode (ID numérique). Les cartes introuvables sont écrites en commentaire (# Nom (ID introuvable)).

      ⚠️ Limitations

      • Toutes les cartes n'ont pas de traduction française officielle ; dans ce cas, le nom anglais est conservé.
      • Les cartes custom VAACT pures (jamais éditées) ne sont ni dans YGOPRODeck ni dans Yugipedia — elles n'auront pas d'image.
      • Pour les cartes anime (comme Pot of Greed), ajoute leur passcode dans le dictionnaire CUSTOM_IDS de script.js.
      • Le champ serial (numéro de set) n'est pas fourni par l'API — laisse vide ou clique RANDOMIZE dans l'éditeur.
