Scripts & CDB

Scripts Finder Officiels

Pour chaque carte custom non taguées (identique à l'officielle) : trouve la carte officielle du même nom dans les CDB officiels, prend son script en remplaçant l'ID par l'ID custom.

Scripts Finder Modifiés

Pour chaque carte custom taguée (effet modifié) : cherche si uune carte officielle a le même nom dans les CDB officiels, copie son script en remplaçant l'ID par l'ID custom pour avoir une base de script à modifier.
