      Détail de la carte

      ⚜️ À propos

      Cet outil permet de rechercher des cartes Yu-Gi-Oh! par leur nom dans plusieurs langues, de générer un JSON compatible avec l'éditeur ygopro.org, de télécharger les illustrations officielles, de traduire des decklists entières, et de convertir des fichiers .cdb EDOPro/YGO Pro en JSON ou en .cdb traduit.

      💾 Base de cartes locale

      Pour des recherches instantanées et zéro requête API, l'app peut télécharger toute la base de cartes (~30 Mo) dans le navigateur (IndexedDB). Une seule fois. Ensuite, tout fonctionne hors-ligne.

      Utilise le bouton 🔄 du header pour synchroniser si une nouvelle version est disponible.

      📦 Traitement .cdb

      Dépose un fichier .cdb (base SQLite EDOPro/YGO Pro) dans l'onglet dédié. Tu peux ensuite :

      • Le traduire — les noms et effets passent en français. Sortie : _fr.cdb.
      • Le convertir en JSON — un JSON par carte (ZIP) + CSV Manager, prêt pour l'éditeur ygopro.org.

      Préserver les effets modifiés : pour les cartes dont l'effet a été modifié par un mod custom (VAACT, Project Ignis, fan-made…), conserve l'effet original du .cdb et ajoute la traduction officielle française en dessous. Chaque bloc est étiqueté avec un tag universel : [Traducteur] pour l'effet original, [Vérificateur] pour l'effet officiel. Les tags sont configurables dans le code (TAG_TRAD / TAG_VERIF). S'applique uniquement à la sortie .cdb.

      🟣 Fallback Yugipedia

      Pour les cartes absentes de la base locale (cartes récentes, errata, etc.), l'app peut interroger l'API de Yugipedia pour récupérer la traduction française officielle.

      Important : cette option est désactivée par défaut et respecte strictement la politique d'utilisation de Yugipedia (1 requête/seconde, User-Agent descriptif, cache 30 jours). Une fois activée, ton choix est mémorisé.

      🌐 Langues supportées

      La recherche accepte les noms de cartes dans toutes les langues gérées par l'API YGOPRODeck :

      🇫🇷 Français
      🇬🇧 Anglais
      🇯🇵 日本語
      🇩🇪 Deutsch
      🇮🇹 Italiano
      🇵🇹 Português

      En mode Auto, la recherche essaie d'abord en français, puis bascule automatiquement en anglais si aucune carte n'est trouvée.

      📄 Format JSON généré

      Le JSON suit le schéma compatible-card du card maker ygopro.org : version, name, level, type, icon, effect, atk, def, serial, copyright, attribute, id, rarity, pendulum, variant, link, layout, boxSize.

      🧹 Cache Yugipedia

      ⚠️ Limitations

      • Toutes les cartes n'ont pas de traduction française officielle ; dans ce cas, le nom anglais est conservé.
      • Les cartes custom (VAACT, Project Ignis, fan-made) ne sont pas sur Yugipedia — le fallback ne les résoudra pas.
      • Le champ serial (numéro de set) n'est pas fourni par l'API — laisse vide ou clique RANDOMIZE dans l'éditeur.
      • Les images ne sont pas stockées localement — elles sont chargées depuis images.ygoprodeck.com (mise en cache navigateur).
