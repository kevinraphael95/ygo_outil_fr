DuelingBook vers CDB

Prend la réponse JSON de load-deck.php (Réseau → XHR → Réponse → Brut → copier) et génère un CDB pour EDOPro. Cartes officielles : fiche officielle copiée (stats, texte, indices str1-16). Customs : stats et effet DuelingBook.

Configuration

Réponse de load-deck.php sauvée en .json ou .txt. Plusieurs fichiers possibles : ils sont fusionnés dans l'ordre de sélection.
Vide = tous les CDB de data/cdb/en du dépôt GitHub ygo_outil_fr.
Séparés par « ; ».
Ex : ton « VAACT S1.cdb » ou le CDB d'un deck déjà fait. CDB, JSON DuelingBook, XML, CSV ou TSV. Même nom de base + mêmes stats + même effet = carte ignorée. Pour XML/CSV/TSV (pas d'effet connu) : le nom suffit.
Utilisé seulement avec « Renuméroter ». Vide : on prend le plus grand ID ≥ 100 000 000 trouvé dans les CDB d'exclusion + 1, sinon l'ID de la 1re carte.

Cartes similaires trouvées

Ces cartes ont le même nom de base que des cartes de tes fichiers d'exclusion, avec un effet ou des stats différents. Coche celles que tu veux garder dans le CDB final (décoché = supprimée).
