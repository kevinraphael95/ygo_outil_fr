DuelingBook vers CDB

Prend la réponse JSON de load-deck.php (Réseau → XHR → Réponse → Brut → copier) et génère un CDB complet : stats, type, race, attribut, niveau, effet, effet de pendule. Aucun CDB officiel nécessaire.

Configuration

Réponse de load-deck.php sauvée en .json. Plusieurs fichiers possibles : ils sont fusionnés.
Vide = tous les CDB de data/cdb/en du dépôt GitHub ygo_outil_fr.
Séparés par « ; ».
Utilisé seulement avec « Renuméroter ».
