YGO Tools
Boîte à outils Yu-Gi-Oh!

XML vers CDB

Lit une liste de cartes et génère un CDB propre. Les doublons (noms ou effets identiques) sont automatiquement supprimés. Les cartes modifiées (ex: Buff, Nerf) reçoivent un effet générique à remplir.

Configuration

Plusieurs fichiers possibles : ils sont fusionnés dans l'ordre de sélection.
Vide = tous les CDB de data/cdb/en du dépôt GitHub.
Les cartes dont le nom de base est déjà dans ces fichiers sont ignorées.
Séparés par « ; ».
Utilisé seulement avec « Renuméroter ».

Console d'exécution

YGO Tools · tout s'exécute dans ton navigateur

Cartes similaires trouvées

Ces cartes ont le même nom de base que des cartes dans vos fichiers d'exclusion. Cochez celles que vous voulez garder dans le CDB final. (Décoché = supprimé).
