Scripts Finder Modifiés

Pour chaque carte custom taguée (effet modifié) : trouve la carte officielle du même nom dans les CDB officiels, copie son script en remplaçant l'ID et ajoute un en-tête d'origine prêt à modifier.

Configuration

Cherché dans la description EN et FR. Insensible à la casse.
Un script d'un sous-dossier « official » est prioritaire sur les variantes (goat, rush…).
Utilisé seulement avec « Ignorer les cartes qui ont déjà un script ».
Les cartes déjà générées sont ignorées (sauf si écrasement forcé).
