Déployer ygocarder sur GitHub Pages

Guide pas-à-pas 100% web sans terminal
Le principe — GitHub construit et publie le site tout seul (GitHub Actions) à chaque modification du code. Tu fais la configuration une seule fois.

1Corriger le homepage dans package.json

  1. Sur ton repo, clique sur le fichier package.json.
  2. Clique sur le crayon ✏️ en haut à droite.
  3. Cherche la ligne homepage. Si tu vois lauqerm.github.io, remplace-la par : 
    "homepage": "https://kevinraphael95.github.io/ygocarder",
  4. Clique sur Commit changes.
Attention — kevinraphael95 doit être ton pseudo GitHub et ygocarder le nom exact de ton repo. Sinon : page blanche.

Déjà bon ? Passe à l'étape 2.

2Créer le fichier de déploiement

  1. Va sur github.com/kevinraphael95/ygocarder
  2. Clique sur Add file puis Create new file
  3. Dans la case du nom, tape exactement : 
    .github/workflows/deploy.yml

    Quand tu tapes les /, GitHub crée les dossiers tout seul.

  4. Colle dans le grand champ de texte le code ci-dessous :
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm install
      - run: npm run build
        env:
          NODE_OPTIONS: --openssl-legacy-provider
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
  1. Clique sur Commit changes… (bouton vert en haut à droite), puis Commit changes dans la fenêtre.
Attention — l'indentation (les espaces au début des lignes) compte. Utilise le bouton Copier, ne retape pas à la main.

3Activer GitHub Pages en mode Actions

  1. Va sur github.com/kevinraphael95/ygocarder/settings/pages
  2. Dans Build and deployment, change Source en GitHub Actions
  3. Rien d'autre à faire, ça s'enregistre tout seul.
Si c'était sur Deploy from a branch, c'est ça qui causait ta page blanche : GitHub affichait ton code source au lieu du site construit.

4Lancer et suivre le déploiement

  1. Va dans l'onglet Actions de ton repo.
  2. Le workflow Deploy to GitHub Pages démarre tout seul après ton commit.

    Rien ne tourne ? Clique sur Deploy to GitHub Pages à gauche, puis Run workflow → Run workflow.

  3. Attends 2 à 5 minutes. Pastille jaune = en cours, coche verte = terminé, croix rouge = erreur.

5Ouvrir le site

Quand c'est vert, ouvre le lien. Fais Ctrl + F5 si tu vois encore l'ancienne page blanche (cache).

Ton site sera accessible ici

https://kevinraphael95.github.io/ygocarder/

Si ça ne marche pas

Croix rouge dans l'onglet Actions

Clique sur le workflow raté, puis sur le job rouge (build). Ouvre l'étape en rouge et regarde la dernière ligne d'erreur.

Erreur Missing script: "build"

Ouvre package.json, regarde la section "scripts" et utilise le nom de la commande qui construit le site.

Erreur path: dist introuvable

Ton projet construit peut-être dans un autre dossier (build par exemple). Dans deploy.yml, remplace path: dist par path: build.

Le site est vert mais la page est toujours blanche

Le chemin de base est faux. Dans package.json, vérifie le champ homepage.

Mettre à jour le site

Chaque modification validée sur main relance le déploiement automatiquement.

Tu n'as plus rien à refaire. Pas de terminal, pas de npm run deploy.
